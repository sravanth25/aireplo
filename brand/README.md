# Aireplo brand files

| File | Use |
|---|---|
| `icon.svg` | The mark (vector). Use anywhere, any size. |
| `favicon.svg`, `favicon-32.png`, `favicon-48.png` | Browser tab icon |
| `apple-touch-icon.png` | iPhone/Android home-screen icon (180×180) |
| `icon-512.png` | WhatsApp Business profile photo, social profiles, app icon (circle-crop safe) |
| `logo-dark.png` / `logo-light.png` | Full logo on dark / white background |
| `logo-transparent-*.png` | Full logo with transparent background (white or dark text) |
| `og-image.png` | Link preview when the site is shared (1200×630) |

Colors: primary green `#22C55E`, lime `#A3E635`, teal `#0F766E`, background `#07090C`, light background `#F8FAFC`.
Wordmark: Bricolage Grotesque ExtraBold, "Ai" in a lime→green gradient, "replo" in white (dark) or `#07090C` (light).
